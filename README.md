# 拾光 · 本地学习记录

单用户、本地运行的学习记录应用。支持添加、查看、编辑、删除记录；按条件分页搜索；从首次使用日起的 GitHub 式日历热力图；根据记录数和已填时长计算相对活跃度百分比；每周回顾；成长节点；本地备份和恢复。

## Windows 桌面版：双击启动

日常使用可打开 [打包好的程序](dist/拾光/拾光.exe)。分发给其他电脑时，发送 `dist/拾光-0.4.0-win64.zip`，让对方解压整个文件夹并双击 `拾光.exe`；不要只移动 `.exe`。压缩包内有使用说明，同目录的 `.sha256` 文件可校验下载是否完整。运行桌面版无需安装 Python，也无需打开命令行或浏览器。它使用系统的 Microsoft Edge WebView2 组件显示独立窗口，只在本机临时端口运行服务，窗口关闭后服务退出。若未检测到 WebView2，程序会明确提示安装地址；可从 [微软官网](https://developer.microsoft.com/en-us/microsoft-edge/webview2) 安装运行时。

应用数据存于 `%LOCALAPPDATA%\ShiGuangLearning\learning.db`。首次升级时，会把旧项目 `data\learning.db` 的记录并入这份数据库，并在 `backups\` 留下合并前副本；旧数据库原文件仍保留。相同编号但内容不同的记录会全部保留。新安装在首次启动时记录首次使用日期；本项目现有数据的首次使用日期为 2026-09-24。操作日志存于同目录的 `logs\app.log`。

需要重新构建桌面版时，在项目目录运行 `powershell -ExecutionPolicy Bypass -File .\build-desktop.ps1`。构建依赖见 `requirements-desktop.txt`，构建后会生成可分发的 ZIP 包和 SHA256 校验文件。数据始终在用户本地目录，升级时关闭程序并替换解压后的程序文件夹，学习记录会保留；在其他电脑首次运行时会创建新的本地数据库。

## 使用与数据含义

- 点击「记录一次学习」或「添加记录」填写日期、类别、内容；时长和成果链接可留空。记录和成长节点的日期只能在首次使用日与今天之间。选中日历日期后，可看当天记录，并编辑或删除。
- 日历从首次使用日开始，按周排列并显示月份和星期标记。活跃度 = 30% × min(记录数 / 8, 1) + 70% × min(已填分钟 / 600, 1)，四舍五入，有记录至少显示 1%。无记录为 0；有记录按 1–25%、26–50%、51–75%、76–100% 分成四档绿色。每日参考值可调整并随备份保存，调整后历史百分比重算，原始记录不变。新增、编辑、删除记录后会自动更新；悬停可看条数、时长、百分比与未填时长提示，点击可看当天记录。黄色小点表示当天有成长节点。
- 「查找历史记录」默认折叠，点击侧栏「查找记录」会展开。输入关键词或选择类别、日期后才查询，每页显示 20 条；点击结果可跳转到对应日期。
- 「每周回顾」按周汇总记录数、有记录的天数、已填写的时长和主题。本周记录每页显示 6 条，可翻页查看全部记录，点击摘要展开全文、时长和成果链接；列表最高 320 像素，展开长记录时在内部滚动。翻页不会影响正在填写的回顾。界面会带出上周写下的下一步，可记录上周行动进展、本周收获与卡点，再确定下一件具体行动；不会自动给学习质量打分。编辑后显示未保存状态，切换周次前会提醒；更新学习记录时会保留尚未保存的回顾草稿。
- 相对活跃度不评价学习质量；未填时长只计记录部分，提示时长数据不完整。旧版本手动填写的强度数据留在原数据库中，但新界面不再读取或修改。
- 成长节点由你手动添加，按日期倒序呈现在时间线上。系统不会从活动量推断学习成长。

## 本地数据、日志与备份

- 统一的 SQLite 数据库存于 `%LOCALAPPDATA%\ShiGuangLearning\learning.db`。首次使用日期保存在数据库中，重启和恢复后保持不变。
- 在页面「备份与恢复」可保存本地备份、下载 `.db` 文件、选择 `.db` 文件恢复。恢复前应用会自动把当前数据库保存到同目录 `backups\before-restore-*.db`；上传文件会先经过完整性和结构检查。也可以在关闭应用后手动复制数据库。
- 操作日志存于 `%LOCALAPPDATA%\ShiGuangLearning\logs\app.log`。日志达到 1 MB 后轮转，保留 3 份旧日志。新日志仅含操作类型、记录编号、日期及参考值设置；不写学习内容、标题或成果链接。旧版本日志可能含手动强度级别。
- 旧项目内的 `data/` 和 `logs/` 已加入 `.gitignore`，不会随项目代码提交。

## 验证

运行 `python -m unittest discover -s tests -v`，会在临时数据库中验证增删改、日期边界、活跃等级、搜索分页、每周回顾、旧回顾字段迁移、备份恢复、旧数据库合并及无效输入。运行 `node --test tests/test_review_ui.cjs` 验证回顾未保存提醒、放弃切换、保存字段与刷新保留草稿。桌面程序可用 `dist\拾光\拾光.exe --smoke-test` 检查打包后的服务，也可用 `--gui-smoke-test` 检查窗口加载（窗口会自动关闭）。

正式发布前还需在另一台干净的 Windows 电脑验证解压启动、备份恢复和替换升级。当前开发机的检查不能替代该项验证；发布验收步骤见 [发布说明](RELEASE_NOTES.md)。

## 当前边界与后续扩展

第一版仅供本机单用户使用，无账号、云同步或 AI 自动评分。相对活跃度采用确定的记录数和已填时长加权规则。没有读取、写入或迁移「大二上学习」项目的 daily 文件。若未来需要集成，建议新增独立的导入/导出模块，明确字段映射与冲突处理，并让当前 SQLite 数据库继续作为本应用的数据源。

日历显示从首次使用日至今天的所有日期；随着使用时间增长，可横向滚动。成长节点目前可新增和删除，尚无编辑入口。时长仅统计填写了时长的记录。请只绑定 `127.0.0.1` 本地使用；当前没有多人访问控制。
